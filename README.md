# IFST
 Projeto IFRN Sport Time, repositório dedicado à disciplina do projeto integrador I. Sistema de agendamento de atividades físicas no ginásio esportivo do IFRN campus Currais Novos.
 
# Problemática
Foi observado no Campus Currais Novos do Instituto Federal de Educação, Ciência e Tecnologia do Rio Grande do Norte (IFRN) que o processo de utilização do ginásio esportivo apresenta dificuldades relacionadas ao controle e à organização dos agendamentos.

# Objetivo
O sistema IFRN Sport Time tem por objetivo centralizar o processo de agendamento para uso do ginásio, permitindo aos usuários consultar horários disponíveis e realizar reservas de forma organizada, enquanto a administração possui maior controle sobre a utilização do ginásio.
